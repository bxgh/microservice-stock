# [Epic E1] 股市日记 MVP · Epic 文档

## 背景

本文档定义自用股市日记应用的最小可用版本（MVP），以打破“持有惯性”等认知陷阱，培养每日大盘体感。

### 已确认前提与冷启动策略
- **单用户自用**：`user_id` 字段保留但默认 `1`，不做复杂的用户隔离隔离与物理多租户。
- **同一 MySQL 实例**：日记系统数据表与已有 A 股数据表混用，不做物理多实例隔离。
- **高复用性**：行情、指标、板块、自选股、真实持仓等数据直接复用现有库表，不重复抓取。
- **实时回测**：回测与异动比对所需的数据通过异步任务或接口动态计算，不存储历史静态快照。
- **政策解耦**：政策引擎虽然已就绪，但 MVP 暂不集成，解耦至 V2 阶段再行接入。
- **打卡高度收拢**：打卡是日记实体的一种特殊形态（`is_checkin=1`），底层存储高度共用，不另起炉灶。
- **防抱死退避**：持仓自查等强打卡任务在持仓数据为空时，自动柔性隐藏或降级为自选股抽查，防抱死崩溃。
- **格言库冷启动**：上线前手工录入 50 条核心名言，确保初期轮询随机数的高覆盖。
