## 问题描述

### 用户反馈
用户界面显示：
```
选中日期: 2025-12-31
K线数据: ✅ 显示 2025-12-31 的数据
复权因子: ❌ 显示"今日同步: 0 条"（实际应显示 8 条）
```

### 根本原因
前端在显示复权因子时，**固定查询今天的数据**，没有根据用户选择的日期动态查询。

```typescript
// 错误逻辑
<div>今日同步: {todayData.count} 条</div>
// 无论选择什么日期，都显示今天的数据
```

## 前端集成指导

### API 接口

**接口地址**: `GET /api/v1/ops/adjust-factor`

**请求参数**:
| 参数 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| date | string | 否 | 日期（YYYY-MM-DD），不传则默认今天 |

**响应格式**:
```typescript
interface AdjustFactorResponse {
  date: string;      // 查询的日期
  count: number;     // 复权因子数量
  codes: string[];   // 示例股票代码（最多10个）
}
```

### 前端调用示例

**方法1: 使用 Axios**
```typescript
import axios from 'axios';

const getAdjustFactor = async (date: string) => {
  const response = await axios.get('/api/v1/ops/adjust-factor', {
    params: { date }
  });
  return response.data;
};

// 使用
const data = await getAdjustFactor('2025-12-31');
console.log(data.count); // 8
```

**方法2: 使用 React Hook**
```typescript
import { useState, useEffect } from 'react';

const useAdjustFactor = (date: string) => {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(false);
  
  useEffect(() => {
    setLoading(true);
    getAdjustFactor(date)
      .then(setData)
      .finally(() => setLoading(false));
  }, [date]);
  
  return { data, loading };
};

// 使用
const { data, loading } = useAdjustFactor(selectedDate);
```

### UI 组件建议

```tsx
const AdjustFactorCard: React.FC<{ selectedDate: string }> = ({ selectedDate }) => {
  const { data, loading } = useAdjustFactor(selectedDate);
  
  if (loading) return <div>加载中...</div>;
  
  const count = data?.count || 0;
  const isHoliday = checkIsHoliday(selectedDate);
  
  return (
    <div className="adjust-factor-card">
      <h3>复权因子</h3>
      <div className="count">
        {selectedDate} 同步: {count} 条
      </div>
      {count === 0 && (
        <div className="tip">
          {isHoliday ? '📅 休市日' : 'ℹ️ 无除权除息事件'}
        </div>
      )}
      {count > 0 && (
        <div className="codes">
          涉及股票: {data.codes.join(', ')}
          {data.codes.length >= 10 && '...'}
        </div>
      )}
    </div>
  );
};
```
