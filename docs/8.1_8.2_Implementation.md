
# 实施报告：元数据补全 (8.1 & 8.2)

针对用户提出的核心字段缺失及细粒度行业分类需求，已完成以下开发与部署工作。

## 1. 核心字段：发行价 (Issue Price)

### 现状问题
MySQL `stock_basic_info` 表及 ClickHouse 缺失原始发行价，无法计算估值倍数。

### 解决方案
1.  **数据库变更**: 在 `stock_basic_info` 表中新增 `issue_price` (DECIMAL 10,2) 字段。
2.  **数据源接入**: 使用 AkShare `stock_ipo_info` 接口获取发行价。
3.  **同步服务**:
    - 开发了 `MetadataService.sync_issue_prices()`。
    - 逻辑：扫描所有 `issue_price IS NULL` 的股票，并发批量获取并更新。
4.  **接口与调度**:
    - 新增接口: `POST /api/v1/metadata/sync/issue-prices`
    - 新增周常任务: 每周六 02:00 自动检查补全。

### 当前状态
- 代码已部署至 `akshare-api`。
- 后台任务已触发，正在为 5700+ 只股票补全发行价。

## 2. 细粒度行业：申万二/三级行业

### 现状问题
原有分类过于宽泛，缺乏申万二/三级行业，影响 PeerSelector 精准度。

### 解决方案
1.  **数据库变更**: 新建 `stock_industry_sw` 表，存储 L1/L2/L3 完整层级代码与名称。
2.  **数据源接入**: 使用 AkShare `sw_index_first/second/third_info` 及成分股接口。
3.  **同步服务**:
    - 开发了 `MetadataService.sync_shenwan_industries()`。
    - 逻辑：构建完整的 L1->L2->L3 行业树，遍历获取 L3 成分股，建立 Stock->Industry 映射并批量写入。
4.  **接口与调度**:
    - 新增接口: `POST /api/v1/metadata/sync/sw-industries`
    - 新增周常任务: 每周六 02:00 自动全量刷新。

### 当前状态
- 代码已部署至 `akshare-api`。
- 后台任务已触发，正在同步全市场申万分类。
