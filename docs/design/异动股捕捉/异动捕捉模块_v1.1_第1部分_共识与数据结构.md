## 背景

盘后体系 L8 已实现"已发生强异动"的捕捉(涨停 / 连板 / 巨量 / 突破 / 龙虎榜),但缺少:

1. **启动前异动**(温和放量、排名跃升、形态蓄势)
2. **陷阱信号**(诱多放量、假突破、高位出货)
3. **多维印证机制**(单一信号噪音大,需要多维共振)
4. **弹性设计**(用户尚未形成轻重缓急判断,系统不应锁死优先级)
5. **可演化的扩展性**(为未来的认知训练系统、命中率反馈机制打基础)

本模块在 L8 现有基础上扩展,产出**统一异动池** + **每日 Top 10 推送清单**,作为后续"观察点系统"的信号供给层。

## 目标

- 每个交易日 17:30 后,产出 3 类异动池统一数据(strong / early / trap)
- 每条异动信号附带**完整多维标签**(价格 / 资金 / 板块 / 催化 / 历史 / 形态 / 异常)
- 每条异动信号附带**多维印证评估**(共振等级 / 反向信号 / 时间共振)
- 综合评分函数支持权重热配置
- 重复跟踪压制(7 日窗口)
- 个人板块偏好加权
- **不预设涨停优先级,通过 Profile 切换实现弹性筛选**

## 范围

- 新建 **9 张表**(数据结构见 E1 各 Story)
- 新增多维度标签体系(约 80 个标签)
- 提供 4 组组合信号(启动前) + 4 类陷阱信号
- 综合评分函数(含共振增强 / 反向抑制)
- 5 个预设 Profile 模板
- 系统生成的中文可解释性说明

## 非目标

- ❌ 主观表态结构(留待观察点系统)
- ❌ 验证规则、假设结构、观测对象设计
- ❌ OCI 场外资金信号(阶段 3 后做)
- ❌ 历史相似性引擎(阶段 2)
- ❌ 信号生命周期追踪表的实际数据填充(本期仅建表)
- ❌ 个性化命中率自学习(阶段 3)
- ❌ 微信小程序前端
- ❌ 数据采集脚本与历史回补(归 Antigravity)

## 核心共识(基线)

> 本节固化前期讨论达成的判断,后续实施以此为准。

### 共识 1:消费层定位

复用盘后体系 L3/L4/L7/L8 的已有数据,**不重做异动捕捉**。新模块只做三件事:**信号优选 → 多维标注 → Top 10 输出**。

### 共识 2:三池结构

| 池 | `pool_type` | 用途 | 数据来源 |
|---|---|---|---|
| 强异动池 | `strong` | 风险机会并存,需要观察 | L8 已有(同步过来) |
| 启动前异动池 | `early` | 真正的高价值训练样本 | 本模块新建 |
| 陷阱信号池 | `trap` | 避错训练的核心样本 | 本模块新建 |

三池**逻辑分离,物理合表**——使用 `pool_type` 字段区分,差异化字段放 `signal_features` JSON。

### 共识 3:启动前异动的优先组合

```
组合 1 龙头预备役  ★ 第一优先级(必做)
组合 3 连板接力候选  ★ 第二优先级
组合 2 箱体突破蓄势  ★ 第三优先级
组合 4 趋势反转早期  ★ 第四优先级
```

### 共识 4:Top 10 配额(默认 Profile)

```
strong 池: 4 条
early 池:  4 条
trap 池:   2 条
total:     10 条

L5 共振:必入,但最多 3 条
L4 共振:优先排序
L3 及以下:按 composite_score 排序
```

**动态填补**:某池不足时,从其他池高分候选填补。**陷阱保留 1 名额**:即便当日陷阱池为空,也保留 1 个最高分位置。

### 共识 5:弹性设计原则

- **不预设"轻重缓急"**:系统不替用户判断哪类涨停更重要
- **多维标签**:每条异动打满标签,涵盖价格/资金/板块/催化/历史/形态/异常 7 大类
- **Profile 切换**:5 个预设模板(默认/短线接力/中线机构/板块研究/全量研究)
- **数据全保留**:被默认隐藏的异动也入库,标注 `excluded_reasons`
- **Profile 切换、个性化学习**留作阶段 2/3 的扩展能力

### 共识 6:多维印证机制

| 印证类型 | 字段 | 说明 |
|---|---|---|
| 横向共振 | `resonance_level` (1-5) | 同时几个维度有信号 |
| 反向印证 | `counter_signals` | 基本面/供给/情绪反向信号 |
| 时间共振 | `temporal_resonance` | 多时间窗口持续性 |
| 可解释性 | `explanation_zh` | 系统生成的自然语言说明 |

### 共识 7:扩展性设计原则

- 每张核心表带 `extra` JSON 兜底字段
- 每张核心表带 `schema_version` 字段(JSON 结构演进时分支兼容)
- 多用户预留 `user_id` 字段(默认 1)
- 标签独立成字典表,便于动态新增
- 派生指标层独立,避免重复计算

### 共识 8:评分参数

| 参数 | 值 | 说明 |
|---|---|---|
| 温和放量阈值 | 量比 5 日均值 ∈ [1.5, 2.5] | 单日量比波动大,均值更稳定 |
| 排名跃升窗口 | T-5 至 T-1 均值 vs T 当日 | 看趋势变化而不是瞬时突变 |
| 重复跟踪压制 | 7 日窗口 | 7 日内已有高分(≥60)异动则压制 |
| 评分权重 | 初期经验权重,1 个月后调优 | 权重存配置表,无需改代码 |
| 共振等级阈值 | L5=5维 / L4=4维 / L3=3维 / L2=2维 / L1=1维 | |
| L5 必入名额上限 | 3 条 | 防止挤占其他配额 |

## E1 · 数据结构

### E1-S1 派生指标层(新增)

> **作为** 系统设计者,**我希望** 把多个异动判定共用的派生指标(量比、排名分位、累计涨幅等)独立到一张表,**以便** 计算一次复用 N 次,降低 SQL 复杂度。

#### E1-S1-T1 DDL

```sql
CREATE TABLE `ads_stock_derived_metrics` (
  `trade_date`            DATE         NOT NULL                  COMMENT '交易日',
  `ts_code`               VARCHAR(20)  NOT NULL                  COMMENT '股票代码',

  -- 量能派生
  `volume_ratio_5d`       DECIMAL(10,4)                          COMMENT '5 日量比均值',
  `volume_ratio_20d`      DECIMAL(10,4)                          COMMENT '20 日量比均值',
  `vol_5d_to_60d`         DECIMAL(10,4)                          COMMENT '5 日均量 / 60 日均量',
  `vol_consistency_days`  TINYINT                                COMMENT '连续满足量比 ∈ [1.5,2.5] 的天数',

  -- 涨跌幅派生
  `cumulative_5d_pct`     DECIMAL(10,6)                          COMMENT '5 日累计涨跌幅',
  `cumulative_20d_pct`    DECIMAL(10,6)                          COMMENT '20 日累计涨跌幅',
  `cumulative_60d_pct`    DECIMAL(10,6)                          COMMENT '60 日累计涨跌幅',
  `amplitude_today`       DECIMAL(10,6)                          COMMENT '当日振幅 (high-low)/pre_close',
  `amplitude_10d`         DECIMAL(10,6)                          COMMENT '10 日总振幅',

  -- 排名派生
  `industry_rank_pct_today`    DECIMAL(6,4)                      COMMENT '行业内涨幅分位(0=最强)',
  `industry_rank_pct_avg_5d`   DECIMAL(6,4)                      COMMENT '前 5 日行业内分位均值',
  `capital_rank_today`         INT                               COMMENT '主力净流入全市场排名',
  `capital_rank_avg_5d`        DECIMAL(8,2)                      COMMENT '前 5 日主力排名均值',

  -- 均线派生
  `dist_to_ma5`           DECIMAL(10,6)                          COMMENT '与 MA5 的乖离率',
  `dist_to_ma10`          DECIMAL(10,6)                          COMMENT '与 MA10 的乖离率',
  `dist_to_ma20`          DECIMAL(10,6)                          COMMENT '与 MA20 的乖离率',
  `dist_to_ma60`          DECIMAL(10,6)                          COMMENT '与 MA60 的乖离率',
  `dist_to_ma250`         DECIMAL(10,6)                          COMMENT '与 MA250 的乖离率',
  `ma_convergence`        DECIMAL(10,6)                          COMMENT 'MA5/10/20 最大相对乖离率(均线粘合度)',

  -- 形态派生
  `box_test_count_60d`    TINYINT                                COMMENT '60 日内压力位测试次数',
  `box_resistance_level`  DECIMAL(16,4)                          COMMENT '识别出的压力位价格',
  `is_first_recovery_ma250` TINYINT(1)                           COMMENT '是否首次站稳 MA250(跌破>60日后)',

  -- 扩展兜底
  `extra_metrics`         JSON                                   COMMENT '其他派生指标',

  -- 元数据
  `schema_version`        VARCHAR(10)  DEFAULT 'v1.0',
  `created_at`            TIMESTAMP    DEFAULT CURRENT_TIMESTAMP,
  `updated_at`            TIMESTAMP    DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

  PRIMARY KEY (`trade_date`, `ts_code`),
  KEY `idx_capital_rank` (`trade_date`, `capital_rank_today`),
  KEY `idx_industry_rank` (`trade_date`, `industry_rank_pct_today`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  ROW_FORMAT=DYNAMIC
  COMMENT='ADS-派生指标层(异动判定的公共依赖)';
```

#### E1-S1-T1-AC 验收标准

> **Given** 全市场 5400 只股票的当日 K 线已入库  
> **When** 派生指标 ETL 完成  
> **Then** `ads_stock_derived_metrics` 当日行数 ≈ 5400,且 `volume_ratio_5d` 非空率 > 95%

### E1-S2 异动信号统一池表(增强)

> **作为** 复盘者,**我希望** 三类异动池(强/启动前/陷阱)在同一张表中按 `pool_type` 区分,带完整多维标签和印证评估,**以便** 综合评分、Top 10 排序、未来命中率分析能在单表内完成。

#### E1-S2-T1 DDL

```sql
CREATE TABLE `ads_l8_unified_signal` (
  `id`                BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  `user_id`           BIGINT UNSIGNED NOT NULL DEFAULT 1        COMMENT '多用户预留,默认 1',
  `trade_date`        DATE            NOT NULL                  COMMENT '交易日',
  `ts_code`           VARCHAR(20)     NOT NULL                  COMMENT '股票代码',
  `name`              VARCHAR(50)     NOT NULL                  COMMENT '股票名称',
  `industry_sw1`      VARCHAR(50)                                COMMENT '申万一级行业',
  `industry_sw3`      VARCHAR(50)                                COMMENT '申万三级行业',

  -- 池与信号类型
  `pool_type`         VARCHAR(16)     NOT NULL                  COMMENT 'strong/early/trap',
  `signal_type`       VARCHAR(40)     NOT NULL                  COMMENT '具体信号类型,见附录 A',
  `signal_subtype`    VARCHAR(40)                                COMMENT '组合信号的子类标识',

  -- 基础行情
  `pct_chg`           DECIMAL(10,6)                              COMMENT '当日涨跌幅,小数',
  `turnover_rate`     DECIMAL(10,6)                              COMMENT '当日换手率,小数',
  `volume_ratio_5d`   DECIMAL(10,6)                              COMMENT '5 日量比均值',
  `amount`            DECIMAL(20,2)                              COMMENT '当日成交额,元',
  `main_net_inflow`   DECIMAL(20,2)                              COMMENT '主力净流入,元',

  -- 信号特征(差异化指标)
  `signal_features`   JSON                                        COMMENT '池差异化指标,见附录 A',

  -- 多维标签体系(核心扩展)
  `tags`              JSON                                        COMMENT '多维度标签数组',
  `manual_tags`       JSON                                        COMMENT '用户手动添加的标签(预留)',

  -- 多维印证
  `resonance_level`       TINYINT                                COMMENT '共振等级 1-5',
  `resonance_dimensions`  JSON                                    COMMENT '具体共振维度详情',
  `resonance_score`       DECIMAL(6,2)                            COMMENT '共振强度评分 0-100',
  `counter_signals`       JSON                                    COMMENT '反向印证信号',
  `counter_signal_score`  DECIMAL(6,2)                            COMMENT '反向信号强度 0-100',
  `temporal_resonance`    JSON                                    COMMENT '不同时间窗口的共振情况',

  -- 评分
  `raw_score`         DECIMAL(6,2)                                COMMENT '原始信号强度,0-100',
  `score_l3_capital`  DECIMAL(6,2)                                COMMENT 'L3 资金维度子分,0-100',
  `score_l4_emotion`  DECIMAL(6,2)                                COMMENT 'L4 情绪维度子分,0-100',
  `score_user_pref`   DECIMAL(6,2)                                COMMENT '个人板块偏好加分,0-100',
  `score_dedup_pen`   DECIMAL(6,2)                                COMMENT '重复跟踪压制扣分,0-100',
  `composite_score`   DECIMAL(6,2)                                COMMENT '综合评分(含共振增强、反向抑制)',

  -- 弹性设计
  `excluded_reasons`  JSON                                        COMMENT '被默认隐藏的理由列表',
  `default_visible`   TINYINT(1)      DEFAULT 1                  COMMENT '默认推送是否显示',

  -- 可解释性
  `explanation_zh`    VARCHAR(500)                                COMMENT '系统生成的中文解释',

  -- 扩展兜底
  `extra`             JSON                                        COMMENT '兜底扩展字段',

  -- 元数据
  `schema_version`    VARCHAR(10)     DEFAULT 'v1.0',
  `compute_version`   VARCHAR(20)                                COMMENT '评分版本号',
  `is_deleted`        TINYINT(1)      DEFAULT 0                  COMMENT '软删除',
  `deleted_at`        DATETIME,
  `created_at`        TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
  `updated_at`        TIMESTAMP       DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_signal` (`user_id`, `trade_date`, `ts_code`, `pool_type`, `signal_type`),
  KEY `idx_date_pool_score` (`trade_date`, `pool_type`, `composite_score`),
  KEY `idx_date_resonance`  (`trade_date`, `resonance_level`, `composite_score`),
  KEY `idx_date_visible`    (`trade_date`, `default_visible`, `composite_score`),
  KEY `idx_code_date`       (`ts_code`, `trade_date`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  ROW_FORMAT=DYNAMIC
  COMMENT='ADS-L8 异动统一池(strong/early/trap),多维标签 + 多维印证';
```

```python
import pandas as pd
from app.utils.db import get_engine

def compute_derived_metrics(trade_date: str):
    """计算派生指标层,写入 ads_stock_derived_metrics"""
    eng = get_engine()
    
    # 拉取 60 日 K 线数据
    sql = """
    SELECT ts_code, trade_date, open, high, low, close, pre_close,
           vol, amount, turnover_rate, avg_vol_20d
    FROM stock_kline_daily
    WHERE trade_date BETWEEN DATE_SUB(:td, INTERVAL 90 DAY) AND :td
    """
    df = pd.read_sql(sql, eng, params={'td': trade_date})
    
    results = []
    for ts_code, g in df.groupby('ts_code'):
        g = g.sort_values('trade_date').reset_index(drop=True)
        if g['trade_date'].iloc[-1].strftime('%Y-%m-%d') != trade_date:
            continue
        
        today = g.iloc[-1]
        
        # 量比派生
        vol_5d = g['vol'].tail(5).mean()
        vol_60d = g['vol'].tail(60).mean()
        vol_ratio_5d = (g['vol'] / g['avg_vol_20d']).tail(5).mean()
        vol_consistency = ((g['vol'] / g['avg_vol_20d']).tail(5)
                           .between(1.5, 2.5).sum())
        
        # 涨跌幅派生
        cum_5d = (today['close'] / g['close'].iloc[-6] - 1) if len(g) >= 6 else None
        cum_20d = (today['close'] / g['close'].iloc[-21] - 1) if len(g) >= 21 else None
        cum_60d = (today['close'] / g['close'].iloc[-61] - 1) if len(g) >= 61 else None
        amplitude_today = (today['high'] - today['low']) / today['pre_close']
        amplitude_10d = (g['high'].tail(10).max() - g['low'].tail(10).min()) / g['pre_close'].iloc[-10]
```

```python
RESONANCE_DIMENSIONS = {

    },

        'negative': ['short_term_only']
    }

def compute_resonance(signal_tags: list) -> dict:
    """计算单个信号的共振情况"""
    dimensions = {}
    hit_count = 0
    
    for dim_name, dim_config in RESONANCE_DIMENSIONS.items():
        positive_hits = [t for t in signal_tags if t in dim_config['positive']]
        negative_hits = [t for t in signal_tags if t in dim_config['negative']]
        
        # 正向标签数 > 反向标签数,视为该维度命中
        is_hit = len(positive_hits) > len(negative_hits)
        
        dimensions[dim_name] = {
            'hit': is_hit,
            'tags': positive_hits  # 只保留正向标签
        }
        if is_hit:
            hit_count += 1
    
    # 共振等级:命中维度数
    resonance_level = min(5, hit_count)  # 上限 5
    
    # 共振强度评分:不仅看维度数,还看标签密度
    total_positive_tags = sum(len(d['tags']) for d in dimensions.values())
    resonance_score = min(100, hit_count * 15 + total_positive_tags * 3)
    
    return {
        'resonance_level': resonance_level,
        'resonance_dimensions': dimensions,
        'resonance_score': resonance_score
    }
```

```python
    FROM ods_holder_trade
    WHERE ts_code = %s

      AND change_type = 'reduce'
      AND change_pct > 0.005
    """
    reduce_df = pd.read_sql(sql_reduce, eng, params=(ts_code, trade_date, trade_date))
    for _, r in reduce_df.iterrows():
        counter['fundamental'].append(f"大股东减持_{r.ann_date}")
    
    # 供给反向(解禁)
    sql_unlock = """
    SELECT ann_date, float_share, float_ratio
    FROM ods_share_unlock
    WHERE ts_code = %s
      AND ann_date BETWEEN %s AND DATE_ADD(%s, INTERVAL 30 DAY)
      AND float_ratio > 0.05
    """
    unlock_df = pd.read_sql(sql_unlock, eng, params=(ts_code, trade_date, trade_date))
    for _, r in unlock_df.iterrows():
        counter['supply'].append(
            f"解禁_{r.ann_date}_{r.float_share/1e8:.1f}亿股"
        )
    
    # 情绪反向(L4 过热)
    if ctx.get('profit_effect_score', 50) > 85:
        counter['sentiment'].append(
            f"板块情绪过热_profit_effect_score={ctx['profit_effect_score']}"
        )
    
    # 计算反向信号强度
    counter_score = (
        len(counter['fundamental']) * 25 +
        len(counter['supply']) * 30 +
        len(counter['sentiment']) * 15
    )
    counter_score = min(100, counter_score)
    
    return {
        'counter_signals': counter,
        'counter_signal_score': counter_score
    }
```

```python
def compute_temporal_resonance(ts_code: str, trade_date: str) -> dict:
    """检查多个时间窗口的信号持续性"""
    eng = get_engine()
    
    # 拉取派生指标
    sql = """
    SELECT trade_date, capital_rank_today, industry_rank_pct_today
    FROM ads_stock_derived_metrics
    WHERE ts_code = %s
      AND trade_date BETWEEN DATE_SUB(%s, INTERVAL 90 DAY) AND %s
    ORDER BY trade_date DESC
    """
    df = pd.read_sql(sql, eng, params=(ts_code, trade_date, trade_date))
    
    if df.empty:
        return {}
    
    today = df.iloc[0]
    
    result = {}
    for window_label, days in [('1d', 1), ('5d', 5), ('20d', 20), ('60d', 60)]:
        if len(df) < days:
            result[window_label] = {'main_inflow': None, 'industry_rank_up': None}
            continue
        
        window_df = df.head(days)
        # 主力净流入持续性:窗口内主力排名平均 < 当日排名(说明当日确实跃升)
        main_inflow_consistent = (
            today.capital_rank_today < window_df['capital_rank_today'].mean()
            if today.capital_rank_today and not window_df['capital_rank_today'].isna().all()
            else None
        )
        # 行业排名持续上升
        industry_up = (
            today.industry_rank_pct_today < window_df['industry_rank_pct_today'].mean()
            if today.industry_rank_pct_today and not window_df['industry_rank_pct_today'].isna().all()
            else None
        )
        
        result[window_label] = {
            'main_inflow': bool(main_inflow_consistent) if main_inflow_consistent is not None else None,
            'industry_rank_up': bool(industry_up) if industry_up is not None else None
        }
    
    return result
```
