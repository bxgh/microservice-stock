## 背景

盘后体系 L8 已实现"已发生强异动"的捕捉(涨停 / 连板 / 巨量 / 突破 / 龙虎榜),但缺少两类高价值信号:

1. **启动前异动**(温和放量、排名跃升、形态蓄势)——价格未充分反映、训练价值最高
2. **陷阱信号**(诱多放量、假突破、高位出货)——避错训练的核心样本

本模块在 L8 现有基础上扩展,产出**统一异动池** + **每日 Top 10 推送清单**,作为后续"观察点系统"的信号供给层。本模块定位为**消费层**——复用 L3/L4/L6/L7/L8 已有数据,不重做异动捕捉。

## 目标

- 每个交易日 17:30 后,产出 3 类异动池统一数据(strong / early / trap)
- 每个交易日 17:30 后,产出 Top 10 推送清单(机会 / 潜力 / 风险三类配额)
- 综合评分函数支持权重热配置(无需改代码即可调参)
- 重复跟踪压制(7 日窗口去重)
- 个人板块偏好加权(用户标记关注板块的异动优先推送)

## 范围

- 新建 1 张统一异动池表 `ads_l8_unified_signal`
- 新建 1 张推送清单表 `app_anomaly_top10_daily`
- 新建 2 张配置维表(评分权重、推送配额)
- 新建 1 张用户偏好表 `dim_user_sector_pref`
- 提供 4 组组合信号(启动前) + 4 类陷阱信号的判定规则
- 提供综合评分函数定义与初始权重

## 非目标

- ❌ 主观表态结构(留待下一轮)
- ❌ 验证规则、假设结构、观测对象设计

## 核心共识(基线)

> 本节固化前期讨论达成的判断,后续实施以此为准。

### 共识 1:消费层定位

复用盘后体系 L3/L4/L7/L8 的已有数据,**不重做异动捕捉**。新模块只做三件事:**信号优选 → 评分排序 → Top 10 输出**。

### 共识 2:三池结构

| 池 | `pool_type` | 用途 | 数据来源 |
|---|---|---|---|
| 强异动池 | `strong` | 风险机会并存,需要观察 | L8 已有(同步过来) |
| 启动前异动池 | `early` | 真正的高价值训练样本 | 本模块新建 |
| 陷阱信号池 | `trap` | 避错训练的核心样本 | 本模块新建 |

三池**逻辑分离,物理合表**——使用 `pool_type` 字段区分,差异化字段放 `signal_features` JSON。

### 共识 3:启动前异动的优先组合

```
组合 1 龙头预备役  ★ 第一优先级(必做)
组合 3 连板接力候选  ★ 第二优先级
组合 2 箱体突破蓄势  ★ 第三优先级
组合 4 趋势反转早期  ★ 第四优先级
```

### 共识 4:Top 10 配额

```
strong 池: 4 条
early 池:  4 条
trap 池:   2 条
total:     10 条
```

**动态填补**:某池不足时,从其他池高分候选填补。**陷阱保留 1 名额**:即便当日陷阱池为空,也保留 1 个最高分位置(可空)。

### 共识 5:评分参数

| 参数 | 值 | 说明 |
|---|---|---|
| 温和放量阈值 | 量比 5 日均值 ∈ [1.5, 2.5] | 单日量比波动大,均值更稳定 |
| 排名跃升窗口 | T-5 至 T-1 均值 vs T 当日 | 看趋势变化而不是瞬时突变 |
| 重复跟踪压制 | 7 日窗口 | 7 日内已有高分(≥60)异动则压制 |
| 评分权重 | 初期经验权重,1 个月后调优 | 权重存配置表,无需改代码 |

## 风险

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| MySQL 5.7 无窗口函数,排名计算复杂易错 | 🔴 高 | 关键排名计算用 Python pandas, SQL 只做基础查询 |
| 组合 4 需跨日跟踪候选,首次实施易遗漏 | 🟡 中 | 用独立 `tmp_combo4_candidates` 表 + Python 调度 |
| 初始权重为经验值,前 1 个月推送质量可能不稳定 | 🟡 中 | 1 个月后用命中率反推调整,权重存配置表无需改代码 |
| 当日某池信号过少,Top 10 不足 | 🟢 低 | 动态填补 + 接受当日不足 10 条(优于硬凑) |
| `signal_features` JSON 结构演进时旧数据兼容 | 🟢 低 | 顶层键标准化,新增字段不删除旧字段 |
| 组合 2 形态判定阈值需要历史回测调优 | 🟡 中 | 上线后跑 3 个月历史数据,统计各阈值下的命中分布 |
| 不同 pool_type 下 raw_score 量纲差异 | 🟢 低 | 各组合内部已归一化到 [0, 100],跨池可比 |

## 度量指标

观察期(上线后 1 个月)收集以下指标用于权重调优:

| 指标 | 目标值 | 用途 |
|---|---|---|
| 日均产出强异动条数 | 30–80 | 验证 L8 同步无遗漏 |
| 日均产出启动前条数 | 5–20 | 组合判定阈值是否过严/过松 |
| 日均产出陷阱条数 | 2–10 | trap 池是否需要降阈值 |
| Top 10 实际填充率 | ≥ 90% | 配额分配合理性 |
| 各池 composite_score 中位数 | 50–70 | 评分函数标定合理性 |
| 重复跟踪压制命中率 | 5%–20% | 7 日窗口是否合适 |
| 用户偏好板块 Top 10 占比 | 30%–50% | ε 权重是否过高/过低 |
