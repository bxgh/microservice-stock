# E7 输出与可视化

**不做花哨 dashboard,做三个核心输出物**。预计耗时 1 周。

## E7-S1 个股基本面卡片

**作为** 研究员,**我希望** 每只研究池股票有一张完整的"基本面卡片",**以便** 我做决策时一眼看到核心信息。

### 任务

- E7-S1-T1 设计卡片 Markdown 模板(参考研报但简洁化)
- E7-S1-T2 卡片包括:基础信息、产业链位置、主营业务拆分、财务画像、行业内位置、风险卡片摘要、跟踪点
- E7-S1-T3 支持转换为 HTML(用于浏览器查看)
- E7-S1-T4 卡片样式参考 obsidian-amber-design 设计系统(炭黑+琥珀金)

### 卡片骨架

```markdown
# {公司名} ({ts_code})

## 基础信息
- 行业: {申万二级}
- 上市板: {主板/科创板/创业板/北交所}
- 实控人: {名称} ({性质: 民企/央企/地方国企})
- 上市日期: YYYY-MM-DD

## 产业链位置
{产业链 mapping 中的位置图,Mermaid 或 ASCII}

## 主营业务拆分
{从 E3 抽取的 business_breakdown}

## 财务画像
{核心指标 + 行业内分位}

## 风险点 (来自 E4)
{risk_card 摘要}

## 跟踪点
- 下次财报披露日: YYYY-MM-DD
- 关键监控指标: ...
- 同业对比关注: ...
```

### 验收标准

- **AC1**: 卡片完整性
  - **Given** 一只研究池股票 ID `002129.SZ`
  - **When** 执行 `generate_card.py --ts_code 002129.SZ`
  - **Then** 生成的 Markdown 卡片包含全部 7 个段落,每个数据点可追溯到原始 E3 抽取或 E4 计算结果

- **AC2**: HTML 渲染
  - **Given** Markdown 卡片已生成
  - **When** 执行 `render_card_html.py`
  - **Then** HTML 文件渲染样式符合"炭黑+琥珀金"设计系统,在浏览器中可正常查看

## E7-S2 行业全景图

**作为** 研究员,**我希望** 半导体和生物合成两个行业有一张"产业链全景图",**以便** 我判断行情扩散路径。

### 任务

- E7-S2-T1 设计行业全景图数据结构(产业链节点 + 公司列表 + 当前位置标记)
- E7-S2-T2 用 Mermaid 或 SVG 生成可视化
- E7-S2-T3 标注每家核心公司的"扩散位置"(核心受益/次级标的/概念蹭车)

### 验收标准

- **AC1**: 全景图生成
  - **Given** 半导体行业产业链 mapping 已维护
  - **When** 执行 `generate_industry_map.py --industry semiconductor`
  - **Then** 输出 HTML 文件,展示上中下游产业链节点(如 EDA → IP → 设计 → 制造 → 封测 → 设备 → 材料),每个节点列出 Top 3-5 公司,标注当前估值分位和机构持仓状态

## E7-S3 异动面板(每日触发汇总)

**作为** 研究员,**我希望** 每天早上有一份"昨日异动汇总",**以便** 我快速了解研究池有哪些公司值得关注。

### 任务

- E7-S3-T1 每日生成"异动报告" Markdown(覆盖前一交易日)
- E7-S3-T2 内容包括:新触发排雷的股票、新生成风险卡片的股票、行情异动的股票、新披露公告的股票
- E7-S3-T3 早上 8:00 推送到邮箱

### 验收标准

- **AC1**: 每日报告
  - **Given** 系统正常运行
  - **When** 每日 08:00 触发
  - **Then** 邮箱收到"YYYY-MM-DD 异动汇总"邮件,内容包含至少 4 个段落(排雷变化、新风险卡片、行情异动、公告披露),每个段落有具体股票列表和关键变化数据
