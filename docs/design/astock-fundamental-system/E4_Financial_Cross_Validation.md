# E4 财务交叉验证

**这一层是整个系统最有价值的部分**——A 股研究的 alpha 就在"识别叙述与数据的偏离"。预计耗时 2 周。

## E4-S1 财务勾稽规则库

**作为** 研究员,**我希望** 系统自动执行常见财务勾稽,**以便** 我快速识别财务异常。

### 任务

- E4-S1-T1 设计规则配置 YAML(每条规则包含名称、计算逻辑、阈值、严重程度)
- E4-S1-T2 实现核心勾稽规则(详见下表)
- E4-S1-T3 规则执行引擎(读取 YAML,自动生成 SQL 或 Python 计算)

### 核心勾稽规则

| 规则 ID | 规则名称 | 计算逻辑 | 阈值 | 严重程度 |
|---|---|---|---|---|
| R001 | 经营现金流/净利润健康度 | 3 年均值 | < 50% 异常 | 高 |
| R002 | 应收账款增速 vs 营收增速 | 应收 yoy - 营收 yoy | > 20pct 异常 | 高 |
| R003 | 存货周转恶化 | 存货周转天数 yoy 变化 | > 30% 异常 | 中 |
| R004 | 研发资本化率突变 | 研发资本化率 yoy 变化 | > 15pct 异常 | 中 |
| R005 | 政府补助占利润比 | 当年补助 / 净利润 | > 30% 高依赖 | 中 |
| R006 | 关联交易占营收比 | 关联交易 / 营收 | > 20% 异常 | 高 |
| R007 | 商誉变化 | 当期商誉 / 上期商誉 | > 1.5 或 < 0.7 异常 | 高 |
| R008 | 利息保障倍数 | EBIT / 利息支出 | < 3 偏低 | 中 |
| R009 | 自由现金流 | 经营现金流 - Capex | 连续 3 年为负异常 | 高 |
| R010 | ROIC vs WACC | ROIC | < 8%(估算 WACC) | 中 |

### 验收标准

- **AC1**: 规则可配置
  - **Given** 规则定义在 `config/financial_rules.yaml`
  - **When** 修改 R001 阈值从 0.5 改为 0.6
  - **Then** 下次执行使用新阈值,无需修改代码

- **AC2**: 全规则执行
  - **Given** 研究池一只公司的最新 5 年财报
  - **When** 执行 `run_financial_rules.py --ts_code 002129.SZ`
  - **Then** 输出该公司在所有 10 条规则上的命中情况,异常规则记录到 `ads_financial_anomalies` 表

## E4-S2 异常识别与 AI 解释

**作为** 研究员,**我希望** 财务异常不仅被识别,还能拿到"叙述 vs 数据矛盾"的对照,**以便** 我快速判断是否需要深挖。

### 任务

- E4-S2-T1 异常识别后,自动从 E3 抽取结果中找到对应的"公司叙述"(如 R002 触发时,找出年报中关于"客户优质、回款及时"的相关描述)
- E4-S2-T2 调用 Opus 4.7 生成对照分析("公司称 XX,但 YY 数据矛盾,关注点:ZZ")
- E4-S2-T3 对照分析结果存储为 `risk_card`,关联到具体股票 and 报告期

### 验收标准

- **AC1**: 叙述-数据对照
  - **Given** 某公司 R002 触发(应收增速远超营收)
  - **When** 调用 AI 生成对照分析
  - **Then** 输出包含三段:① 数据事实(具体数字)② 公司叙述(从年报中找到的相关原文)③ 矛盾点与建议关注的方向

- **AC2**: 多规则聚合
  - **Given** 一家公司同时触发 R001、R002、R007 三条规则
  - **When** 生成 risk_card
  - **Then** AI 综合分析三条规则的关联性,识别可能的"利润粉饰"或"现金流恶化"等组合模式

## E4-S3 风险卡片生成

**作为** 研究员,**我希望** 每只研究池股票有一张"风险卡片",**以便** 我决策时一眼看到所有风险点。

### 任务

- E4-S3-T1 设计风险卡片 Markdown 模板
- E4-S3-T2 卡片内容包括:基础信息、触发的规则列表、每条规则的数据 + 叙述对照、综合评级
- E4-S3-T3 卡片生成后存储到 `/data/risk_cards/{ts_code}_{report_period}.md`

### 验收标准

- **AC1**: 卡片生成
  - **Given** E4-S1 和 E4-S2 已运行
  - **When** 执行 `generate_risk_card.py --ts_code 002129.SZ --period 2024Q4`
  - **Then** 生成的 Markdown 文件包含至少 4 个段落(基础信息、规则触发、数据-叙述对照、综合评级),且每条数据都有原文引用或财报字段引用
