# 五维度量化分析体系设计文档

## 1. 体系概述

五维度量化分析体系（Five-Dimension Quantitative Analysis System）旨在通过多源异构数据，从五个独立且互补的维度对上市公司进行全方位画像。该体系不依赖单一指标，通过雷达图形式展示个股在**权利 (Power)**、**筹码 (Chips)**、**能量 (Energy)**、**信息 (Information)** 和 **博弈 (Game)** 五个方面的综合表现。

## 2. 维度定义与核心指标

### 2.1 权利维度 (Power)
**定义**: 衡量公司背后的政策支持度、国资背景力度及管理层信心。
**核心假设**: 政策红利和“国家队”持仓是A股长牛的核心驱动力。
**量化指标**:
- **P1 (政策支持度)**: 行业政策关键词命中率 (来源: 新闻/公告)。
- **P2 (国资背景)**: 实控人属性及“国家队”持仓比例。
- **P3 (管理层信心)**: 董监高近期增持金额净值。

### 2.2 筹码维度 (Chips)
**定义**: 衡量筹码的集中程度、锁定状态及持有成本。
**核心假设**: 筹码越集中，主力控盘能力越强；解禁压力越小，抛压预期越低。
**量化指标**:
- **C1 (筹码集中度)**: 股东户数变化率 (负相关) 及前十大股东持股占比。
- **C2 (解禁压力)**: 未来 30/60/90 天解禁市值占比 (负相关)。
- **C3 (大宗交易)**: 近期大宗交易溢价率及成交量。

### 3.3 能量维度 (Energy)
**定义**: 衡量股价上涨的动能、资金活跃度及趋势强度。
**核心假设**: 量价配合是上涨的基础，资金流入是上涨的燃料。
**量化指标**:
- **E1 (资金动能)**: 日均成交额、量比、换手率。
- **E2 (趋势强度)**: 均线多头排列得分、RSI/MACD 技术指标状态。
- **E3 (板块共振)**: 所属行业/概念板块的整体涨幅排名。

### 2.4 信息维度 (Information)
**定义**: 衡量市场对公司的关注度、预期差及情绪状态。
**核心假设**: 关注度从低到高的过程伴随股价上涨，过热则见顶（舆情反指）。
**量化指标**:
- **I1 (舆情热度)**: 股吧/社区发帖量斜率、阅读量。
- **I2 (分析师预期)**: 研报评级调升家数、业绩预告超预期幅度。
- **I3 (情绪评分)**: 文本情感分析得分 (NLP)。

### 2.5 博弈维度 (Game)
**定义**: 衡量主力资金（游资、机构、外资）的博弈状态与流向。
**核心假设**: 聪明钱（Smart Money）的流向具有先导性。
**量化指标**:
- **G1 (龙虎榜)**: 机构净买入额、知名游资上榜情况。
- **G2 (北向资金)**: 沪深港通持股变动及净流入。
- **G3 (杠杆情绪)**: 融资买入额占比 (两融余额变化)。

## 3. 评分模型 (Scoring Model)

每个维度总分 100 分，最终形成五维雷达图。

### 3.1 归一化处理
不同量纲的数据（如金额、百分比、次数）需通过 **Min-Max Normalization** 或 **Z-Score** 映射到 0-100 区间。

### 3.2 评分算子示例 (筹码维度)
```python
def score_chips(holder_change_pct, top10_ratio, restricted_ratio):
    # 股东户数减少是利好 (反向映射)
    s1 = normalize(holder_change_pct, min=-30, max=30, inverse=True)
    
    # 十大股东占比高是利好
    s2 = normalize(top10_ratio, min=0, max=90)
    
    # 解禁压力大是利空 (反向映射, 权重较高)
    s3 = normalize(restricted_ratio, min=0, max=50, inverse=True)
    
    return 0.4 * s1 + 0.3 * s2 + 0.3 * s3
```

## 4. 数据库设计规划

为支持上述指标，需要在 `stock_data` 数据库中扩展以下表结构：

### 4.1 筹码相关
- `stock_restricted_release`: 限售股解禁流水
- `stock_block_trade`: 大宗交易记录

### 4.2 博弈相关
- `stock_lhb_detail`: 龙虎榜每日明细
- `stock_margin_detail`: 融资融券每日交易
- `stock_north_funds`: 北向资金每日持仓

### 4.3 信息相关
- `stock_sentiment_daily`: 每日舆情热度统计
- `stock_analyst_rank`: 分析师评级记录
