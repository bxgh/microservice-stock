## 编码规范

### 1. 异步与并发 (关键)

```python
# ✅ 正确: 使用 async/await
async def get_stock_data(code: str) -> dict:
    async with httpx.AsyncClient() as client:
        response = await client.get(f"{API_URL}/{code}")
        return response.json()

# ❌ 错误: 阻塞同步调用
def get_stock_data(code: str) -> dict:
    response = requests.get(f"{API_URL}/{code}")  # 会阻塞事件循环
    return response.json()
```

**规则**:
- **异步优先**: 所有 I/O 操作(网络、文件)使用 `async/await`
- **线程安全**: 修改共享状态时**必须**使用 `asyncio.Lock()`
- **避免全局可变状态**: 使用依赖注入代替全局变量

### 2. 资源管理

```python
# ✅ 正确: 使用 try...finally 确保资源释放
async def fetch_data():
    client = None
    try:
        client = await create_connection()
        return await client.query()
    finally:
        if client:
            await client.close()

# ✅ 更好: 使用上下文管理器
async def fetch_data():
    async with create_connection() as client:
        return await client.query()
```

**规则**:
- **生命周期方法**: 服务类必须实现 `initialize()` 和 `close()` 方法
- **资源清理**: **必须**使用 `try...finally` 确保资源释放
- **上下文管理器**: 优先使用 `async with` 处理资源

### 3. 错误处理

```python
# ✅ 正确: 特定异常 + 上下文日志
from app.utils.logger import get_logger

logger = get_logger(__name__)

async def get_finance(code: str):
    try:
        data = await akshare_client.fetch(code)
        return data
    except TimeoutError as e:
        logger.error(f"获取财务数据超时: code={code}, error={e}")
        raise HTTPException(status_code=504, detail="数据源超时")
    except ValueError as e:
        logger.warning(f"无效股票代码: code={code}")
        raise HTTPException(status_code=400, detail="无效股票代码")

# ❌ 错误: 捕获裸 Exception
except Exception as e:
    pass  # 吞掉异常,无法排查问题
```

**规则**:
- **特定异常**: 使用具体异常类型 (TimeoutError, ValueError 等)
- **日志上下文**: 记录函数名、参数、错误详情
- **错误响应**: 返回标准错误格式 (见下文)

### 4. 日志规范

**必须使用 JSON 格式日志**,包含 `request_id`:

```python
import uuid
from fastapi import Request

@app.middleware("http")
async def add_request_id(request: Request, call_next):
    request_id = str(uuid.uuid4())[:8]
    request.state.request_id = request_id
    response = await call_next(request)
    response.headers["X-Request-ID"] = request_id
    return response
```

**日志输出格式**:
```json
{
  "timestamp": "2025-12-20T19:30:00+08:00",
  "level": "INFO",
  "request_id": "a1b2c3d4",
  "message": "获取财务数据成功",
  "code": "600519",
  "duration_ms": 125
}
```

### 5. 时间与时区

```python
from datetime import datetime
import pytz

# ✅ 正确: 始终使用上海时区
CST = pytz.timezone("Asia/Shanghai")

def get_current_time():
    return datetime.now(CST)

def format_date(date: datetime) -> str:
    return date.astimezone(CST).strftime("%Y-%m-%d")
```

**规则**:
- **时区**: **必须**使用 `Asia/Shanghai` (北京时间)
- **交易时间**: A股交易时段 09:30-11:30, 13:00-15:00

## PyWencai 特殊规范

由于同花顺问财有严格的反爬限制,需特殊处理:

### 1. 频率控制

```python
import asyncio

class WencaiRateLimiter:
    """限制请求频率: 约10次/分钟"""
    
    def __init__(self, max_requests: int = 10, window: int = 60):
        self.semaphore = asyncio.Semaphore(max_requests)
        self.window = window
    
    async def acquire(self):
        await self.semaphore.acquire()
        asyncio.create_task(self._release_after_delay())
    
    async def _release_after_delay(self):
        await asyncio.sleep(self.window)
        self.semaphore.release()
```

### 2. 错误处理

```python
# 预期失败率约 30%,需重试机制
MAX_RETRIES = 3
RETRY_DELAY = 5  # 秒

async def query_wencai(q: str):
    for attempt in range(MAX_RETRIES):
        try:
            return await wencai_client.query(q)
        except CaptchaError:
            logger.warning(f"问财验证码错误,重试 {attempt + 1}/{MAX_RETRIES}")
            await asyncio.sleep(RETRY_DELAY)
    raise HTTPException(status_code=503, detail="问财服务暂时不可用")
```
