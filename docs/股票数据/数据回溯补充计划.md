# 五维度数据深度补充计划

## 1. 现状评估与目标

目前系统已建立全量 Market 维度数据及基本的其他维度数据框架。但 Chip, Game, Information 维度的历史数据严重缺失，无法支持回测分析。

**目标**: 将所有核心维度的数据回溯补充至 **至少3年 (2023-01-01 起)**，关键高频数据（如龙虎榜、北向）补充至 **5年 (2021-01-01 起)**。

## 2. 补充策略

### 2.1 龙虎榜 (LHB) - 优先级: 高
*   **现状**: 40+ 条 (仅单日)
*   **目标**: 补充 2021-01-01 至今的数据。
*   **数据量**: 约 250(天) * 5(年) * 50(榜单) ≈ 62,500 条。
*   **API**: AkShare `stock_lhb_detail_em` (按日期范围)。
*   **执行**: 
    1. 开发批量脚本 `scripts/init_lhb_history.py`。
    2. 按月分片请求，避免超时。
    3. 入库 `stock_lhb_daily`。

### 2.2 北向资金 (North Funds) - 优先级: 中
*   **现状**: 1,124 条 (极少)
*   **目标**: 补充 2021-01-01 至今的**每日个股持仓**。
*   **难点**: AkShare `stock_hsgt_hold_stock_em` 每个交易日数据量大 (2000+ 只股票)。
*   **策略**: 
    1. 仅对**成分股**（如沪深300、中证500）进行全量回溯。
    2. 或按日循环拉取全市场数据（耗时较长，需后台运行）。
    3. 入库 `stock_north_funds_daily`。

### 2.3 融资融券 (Margin) - 优先级: 中
*   **现状**: 每日更新正常，历史缺失。
*   **目标**: 补充 2023-01-01 至今。
*   **策略**: AkShare `stock_margin_detail_sse` / `szse`。按股票循环拉取（API通常提供单只股票的历史列表），适合多线程并行。

### 2.4 分析师评级 (Analyst Rank) - 优先级: 低
*   **现状**: 200+ 条
*   **目标**: 2023-01-01 至今。
*   **API**: AkShare `stock_research_report_em`
*   **策略**: 该接口返回数据量较大，一次性拉取需注意内存。可按日期或分页拉取。

### 2.5 市场情绪 (Sentiment) - 优先级: 低
*   **现状**: 1 条
*   **说明**: 情绪数据具有瞬时性，历史回溯意义有限（很难获取当年的实时热度）。
*   **决策**: **放弃历史回溯**，专注于从今日起的高质量积累。

## 3. 执行计划 (Timeline)

- [ ] 编写 `scripts/backfill/backfill_lhb.py`：回溯龙虎榜。

### 阶段三：自动化与校验 (Day 6)

## 4. 脚本规范
所有回溯脚本必须：
1. **幂等**: 可重复运行，使用 `INSERT IGNORE` 或 `ON DUPLICATE KEY UPDATE`。
2. **限流**: 调用 AkShare 接口时增加 `time.sleep`，避免被封禁。
3. **日志**: 输出详细进度到日志文件。
4. **断点续传**: 记录已完成的日期/股票代码，失败后可接续运行。
