# 股东数据源说明

## 1. 采集途径
股东数据主要源自**东方财富 (Eastmoney)** 披露的公开财务数据。

## 2. 接口细节 (`akshare-api`)
我们使用了经过封装的 `akshare-api` 服务中的 `/api/v1/shareholder/{code}` 接口。

### 采集逻辑
- **股东户数**: 调用 `akshare.stock_zh_a_gdhs`（及底层对应接口）。
- **十大股东**: 调用 `akshare.stock_zh_a_sdgd`。
- **采集策略**:
  - 默认情况下：只抓取最新的 10-20 条记录，用于快速更新。
  - `all=true` 模式：抓取全量历史（最高 5000 条），用于系统初始化。

## 3. 字段映射
- `date` -> `END_DATE` (截止日期)
- `count` -> `HOLDER_COUNT` (持股人数)
- `change` -> `HOLDER_COUNT_CHANGE` (变动比例)

## 4. 注意事项
- 股东数据通常随**一季报、半年报、三季报和年报**定期更新。
- 部分公司会在交易所互动易平台不定期披露最新股东人数，系统会自动在采集时尝试捕捉这些最新的非定期时点数据。
