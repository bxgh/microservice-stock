# 股东数据同步任务指引

## 1. 批量初始化脚本
脚本位置：`scripts/init_shareholder_data.py`

### 功能
自动从 `stock-codes` 服务获取所有已上市 A 股列表，并调用 `stock-manager-api` 进行分批同步。

### 使用方法
```bash
# 进入项目根目录
cd /home/ubuntu/microservice-stock

# 1. 全量初始化 (获取所有可用历史数据)
python3 scripts/init_shareholder_data.py --all

# 2. 增量初始化 (仅同步最近的变动)
python3 scripts/init_shareholder_data.py

# 3. 限制数量测试 (例如仅测试前10只)
python3 scripts/init_shareholder_data.py --limit 10
```

---

## 2. 补全/故障重试脚本
脚本位置：`scripts/retry_init.py`

### 适用场景
- 初始化脚本因网络或超限中断。
- 部分股票因数据质量导致入库报错后，修复代码或表结构后的二次同步。

### 原理
该脚本会主动比对数据库中已有的股票代码与全市场代码，仅同步**缺失**的部分。

### 使用方法
```bash
python3 scripts/retry_init.py
```

---

## 3. 运维建议
- **同步频率**: 建议**每日收盘后**运行一次增量同步。
- **并发控制**: 脚本默认并发度为 2，建议不要设置得过高，以免触发 `akshare-api` 上游接口的限流。
- **容器环境**: 脚本中访问接口采用了 `localhost`。如果需要在容器内部运行，请将 `STOCK_CODES_URL` 修改为 `http://stock-codes:8000`。
