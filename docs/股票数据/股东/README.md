# 股东数据 (Shareholder Data) 模块说明

## 1. 模块定位
本模块负责 A 股上市公司的股东相关数据，主要包括：
- **股东户数**: 历史各时点的股东总户数、户数变动、户均持股市值等。
- **前十大股东**: 各定期报告披露的十大流通股东明细（排名、名称、股数、占比、变动情况）。

数据流向：`AkShare (Eastmoney) -> akshare-api -> stock-manager-api -> MySQL`

## 2. 核心功能
- **实时/历史获取**: 通过 `akshare-api` 从东方财富接口抓取数据。
- **持久化存储**: 自动将获取的数据写入 MySQL 数据库，支持增量更新 (UPSERT)。
- **批量初始化**: 支持全市场 5000+ 股票的一键初始化入库。
- **多维度查询**: 提供按股票代码查询户数历史，以及查询特定日期的十大股东接口。

## 4. 快速入门
如果你需要同步一只股票的股东数据：
```bash
curl -X POST "http://localhost:8004/api/v1/shareholders/sync/600519?all=true"
```

查询该股票最新的股东户数：
```bash
curl "http://localhost:8004/api/v1/shareholders/count/600519?limit=5"
```
