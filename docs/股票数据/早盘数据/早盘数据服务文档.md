# 早盘数据服务 (Pre-Market)

## 1. 概述
早盘数据服务负责在开盘前同步关键的市场事件和状态，以支持日内策略决策。

- **核心时间窗**: 08:30 - 09:15
- **主要数据**: 业绩预告、除权除息、新股列表、停复牌状态。
- **服务载体**: `stock-manager-api` (调度与存储), `akshare-api` (数据源)。

## 2. 数据库表结构

### 2.1 业绩预告 (`stock_performance_forecast`)
记录上市公司发布的业绩预告、快报信息。

| 字段名 | 类型 | 说明 | 备注 |
| :--- | :--- | :--- | :--- |
| `id` | INT | 自增ID | |
| `ts_code` | VARCHAR(20) | 股票代码 | 标准后缀 (如 `000001.SZ`) |
| `report_period` | DATE | 报告期 | 如 `2025-12-31` |
| `notice_date` | DATE | 公告日期 | |
| `type` | VARCHAR(255) | 预告类型 | 如 "预增", "扭亏", "首亏" 等 |
| `growth_range` | VARCHAR(255) | 变动幅度 | 如 "50% - 80%" |
| `created_at` | TIMESTAMP | 创建时间 | |
| `updated_at` | TIMESTAMP | 更新时间 | |

- **唯一约束**: `uk_code_period (ts_code, report_period)`

### 2.2 除权除息日程 (`stock_xr_schedules`)
记录股票的除权除息日信息。

| 字段名 | 类型 | 说明 | 备注 |
| :--- | :--- | :--- | :--- |
| `id` | INT | 自增ID | |
| `ts_code` | VARCHAR(20) | 股票代码 | |
| `ex_date` | DATE | 除权除息日 | |
| `bonus_ratio` | DECIMAL(10,4) | 送转比例 | 每10股送转X股 |
| `cash_div` | DECIMAL(10,4) | 派现金额 | 每10股派X元 |

- **唯一约束**: `uk_code_date (ts_code, ex_date)`

## 3. 定时调度任务 (Schedule)

| 任务ID | 时间 | 频率 | 描述 |
| :--- | :--- | :--- | :--- |
| `daily_performance_forecast_sync` | **08:45** | 每日 | 同步未来4个报告期的业绩预告数据 |
| `daily_suspension_morning_sync` | **09:15** | 每日 | 同步当日早盘停复牌状态 |

## 4. API 接口

### 4.1 获取业绩预告 (AkShare)
*   **服务**: `akshare-api`
*   **接口**: `GET /api/v1/forecast?period=YYYY-MM-DD`
*   **描述**: 获取指定报告期的所有预告数据。
