# 停复牌数据文档

## 1. 概述
停复牌数据记录了 A 股市场股票的停牌与复牌状态。该数据每日更新，用于剔除停牌股票、处理交易日历逻辑以及分析停牌原因。

- **数据源**: 
    - **AkShare**: `stock_tfp_em` (主要来源，涵盖早盘公告)
    - **BaoStock**: `query_all_stock` (辅助验证，tradeStatus=0)
- **更新频率**: 每日
- **服务**: `stock-manager-api` (调度与存储), `akshare-api` (数据采集接口)

## 2. 数据库结构

存储位置：腾讯云 MySQL 数据库。

### 停牌表 (`stock_suspensions`)

| 字段名 | 类型 | 说明 | 备注 |
| :--- | :--- | :--- | :--- |
| `id` | INT | 自增ID | 主键 |
| `ts_code` | VARCHAR(20) | 股票代码 | 标准后缀格式 (如 `300912.SZ`) |
| `trade_date` | DATE | 停牌日期 | |
| `is_suspended` | TINYINT(1) | 是否停牌 | 1=是 |
| `reason` | VARCHAR(255) | 停牌原因 | 如"刊登重要公告" |
| `created_at` | TIMESTAMP | 创建时间 | |
| `updated_at` | TIMESTAMP | 更新时间 | |

- **唯一约束**: `uk_code_date (ts_code, trade_date)`
- **索引**: `idx_date`, `idx_code`

## 3. API 接口

### 3.1 获取每日停牌数据 (AkShare)
*   **服务**: `akshare-api`
*   **接口**: `GET /api/v1/suspension/daily?date=YYYY-MM-DD`
*   **描述**: 直接调用 AkShare 接口获取当日或最近交易日的停牌列表。

### 3.2 同步停牌数据 (Stock Manager)
*   **服务**: `stock-manager-api`
*   **接口**: `POST /api/v1/suspensions/sync`
*   **参数**: 
    - `start_date` (YYYY-MM-DD)
    - `end_date` (YYYY-MM-DD)
*   **描述**: 触发后台任务，批量同步指定日期范围的停牌数据入库。

## 4. 定时调度任务

| 任务ID | 执行时间 | 服务 | 说明 |
| :--- | :--- | :--- | :--- |
| `daily_suspension_morning_sync` | 每日 09:15 | `stock-manager` | 早盘同步，获取当日发布的停牌公告 |
