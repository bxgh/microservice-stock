01

三个核心观点的评判

Critical Review · Market Structure Foundations
VIEWPOINT 01
基本成立
A股是一个半封闭市场
资本账户尚未完全开放、人民币不可自由兑换、外资通过陆股通等限定通道进入,加上涨跌停板和T+1制度,A股确实是被"管道化"连接到全球市场的体系。但需要修正:北向资金的边际定价权显著存在,情绪传导也是开放的。更准确的表述是:A股是资金通道半封闭、但情绪与估值锚部分全球化的市场。
VIEWPOINT 02
方向正确 · 需细化
机构主导的结构性牛市,聚焦政策导向行业
机构定价权较2015年前明显增强,A股的产业行情高度依赖政策催化。但需要注意:个人投资者贡献的换手率长期在60%以上——A股是"机构主导中长期定价、散户和游资推动日内波动"的双层市场。此外,机构内部并不同质——公募追逐景气度、保险偏好红利低波、外资看ROE和现金流、国家队负责维稳,它们之间的博弈本身就是结构性行情的重要驱动力。
VIEWPOINT 03
部分成立 · 需拆分
量化和游资在大势好时做小盘股连板
把量化和游资放在一起描述会模糊两者本质上的差异。游资的核心打法是情绪驱动的连板接力,本质是博弈散户跟风资金。而量化资金的逻辑几乎相反——依赖统计套利和因子暴露,偏好小盘股是因为波动率高、流动性溢价高、因子有效性强。2024年初的小微盘流动性危机清楚地展示了:量化的小盘暴露是因子拥挤,而非主动的题材投机。两者在小盘股上确实经常"相遇",但相遇不等于同盟。
02

A股资金的四层结构

Four-Tier Capital Stratification

理解A股行情的关键往往是判断:现在哪一层资金在加仓、哪一层在撤退。四个层次的资金在不同宏观环境下轮动主导,每一层都有独特的目标函数、持有期和风险偏好。

Tier I 大盘价值层
以险资、外资配置盘、社保和国家队为主体,追求长期稳健回报,偏好低估值、高股息、现金流稳定的大市值标的。换手率低,持有期以季度和年度计算,是A股真正的"压舱石"资金。

外资配置盘
社保
国家队
Tier II 大盘成长层
以公募基金为核心,追求景气度和成长性,持有期以月度和季度为单位。这是制造结构性牛市核心资产行情的主力,白酒、新能源、医药等历次主线行情背后都是它们的身影。

部分外资
头部私募
Tier III 中小盘成长层
以中小私募和量化基金为主,通过因子暴露和高换手获取alpha。偏好流动性好、波动率高的中小盘股。这一层的资金动作隐蔽但影响巨大,是2024年初小微盘流动性危机的主角。

Tier IV 小微盘题材层
游资和散户共同构成,情绪驱动、题材驱动、连板接力。持有期以天为单位,本质是博弈跟风资金。这一层在风险偏好高、政策催化密集时极度活跃,是A股独特生态的底层底色。

04

四种市场状态识别

Market State Recognition Engine

把十六个指标合成为四种市场状态,每种状态有清晰的进入和退出条件,对应完全不同的操作策略。

A
STATE A · INSTITUTIONAL TREND

机构主导的趋势市

✓ 北向配置盘连续净流入
✓ 公募仓位上行但未达极值
✓ 大盘相对小盘走强
✓ 行业轮动速度慢(主线明确)
✓ DR007平稳,M1同比改善
✓ 美债收益率不构成压制
✓ 量化拥挤度低
B
STATE B · THEMATIC SPECULATION

游资主导的题材市

✓ 北向不明显,公募仓位中性
✓ 两融占比快速上行
✓ 小盘强于大盘
✓ 行业轮动速度快
✓ 涨停股以小市值为主
✓ 连板高度持续走高
✓ 游资席位活跃,炸板率低
C
STATE C · QUANT DRIFT · DANGER

量化主导的小盘漂移

✓ 北向中性,小微盘持续跑赢
✓ 指增超额收益持续累积
✓ IC/IM贴水扩大
✓ 行业轮动极快但波动率不高
⚠ 表面平静实则因子拥挤
⚠ 容易突发流动性危机
D
STATE D · DEFENSIVE

避险防御市

✓ 北向流出,公募仓位下降
✓ 两融余额收缩
✓ 红利低波指数走强
✓ 大盘价值占优
✓ DR007或美债快速上行
✓ 成交额萎缩,PCR走高
✓ 新增开户低迷
05

状态对应策略匹配

State-Based Strategy Playbook
A

跟随策略 · 机构趋势市

核心持仓(60%):政策主线行业的龙头股,持有期1-3个月,跟随北向和公募加仓节奏。重点参考公募季报重仓股变化和北向月度增持榜。

卫星持仓(20-30%):主线行业的二线弹性标的,等待机构补仓扩散。

关键原则:这个状态下不要做高抛低吸,趋势性行情的回撤往往就是最后的上车机会。

Position
70-90%
Hold Period
1-3个月
Exit Signal
公募仓位>88% + 北向配置盘转出
B

题材接力 · 游资题材市

打法:不参与首板(信息劣势),专注强势首板次日回踩不破均线或二板分歧转一致的卡位。每个题材最多持有2-3天,严格执行隔日卖出。

品种选择:流通市值30-100亿的中小盘股,成交活跃,有明确题材催化。

关键原则:题材市的核心是情绪管理而非基本面,亏损单必须当日止损,绝不留隔夜亏损票。

Position
40-60%
Hold Period
2-3天
Exit Signal
炸板率连续2日>30% 或 高度板骤降
C

警戒与对冲 · 量化漂移

这是最容易亏钱的状态,因为表面平静。策略上转向高股息、低估值、流动性好的大盘股,或者直接配置红利ETF。

对冲工具:如果有期货账户,可以做空IC或IM对冲小盘暴露。

关键原则:永远不要在小微盘相对强度的最高点追入,这是2024年1月最惨痛的教训。

Position
30-50%
Avoid
小微盘 / 高拥挤因子
Exit Signal
小微盘相对强度走弱 + IC贴水收敛
D

现金为王 · 防御市

核心持仓:红利低波(银行、煤炭、运营商、长江电力等)、黄金股、债券型基金。

机会捕捉:等待状态切换信号——通常是政策超预期、汇金入场(ETF异常申购)、或DR007和美债收益率的同步回落。

关键原则:防御市最大的错误是过早抄底。等待右侧确认信号(成交额放大+北向回流+公募新发回暖)再加仓。

六条不可妥协的原则

Six Non-Negotiable Principles
i
数据准确性优于一切
最怕的不是bug,是数据错了你不知道。所有数据源做交叉校验,宁可少一个指标,不要一个错的指标。
ii
先解决有没有,再解决好不好
不要陷入完美主义。先用最简单的方式实现完整链路,跑起来再说。如果数据流没打通,一切都是空的。
iii
所有阈值必须可配置
A股的市场结构一直在变。把所有判定阈值放到配置文件,定期review,而不是硬编码在代码里。
iv
日志与审计要完整
每次拉数据、每次状态判定、每次告警触发,都要写日志。出问题时能追溯。结构化日志是底线。
v
警惕过拟合
不要为了让回测好看而不断调阈值。在样本外数据上验证有效性。宁可粗糙稳健,不要精致脆弱。
vi
人在回路
系统是辅助决策的,不是替代决策的。永远保留人工干预的入口。关键时刻必须由人来拍板。
"市场每个阶段都有它的主角资金,你要做的是认出主角、跟上节奏,而不是和主角对抗。"
