03 · KEY INSIGHTS · 观察

几个重要观察

01
"四锚共振"是最美的时刻，也是最危险的前夜。
宁德时代当下接近全面共振，这是投资最舒服的状态。但要警惕：共振是向"极致共识"演化的过程，一旦达到极致就会反转。理想的买点是共振刚启动时（阶段 2–3），而不是已到阶段 4+。
02
"盈利锚动摇"并不等于立即卖出。
茅台盈利动摇，但因为筹码锚极其稳定、估值已反映悲观预期，反而形成了保护垫。真正危险的是"盈利锚动摇 + 筹码松动 + 估值在高位"的组合（这才是戴维斯双杀）。
03
"高股息"是对抗情绪锚的最强工具。
中国神华的盈利其实也在下滑，但高分红 + 长线资金锁仓使它不受情绪扰动。这类标的的核心看点永远是"分红持续性"，而非短期股价。
04
"高成长+高估值"是最大的双刃剑。
寒武纪是最典型的"盈利锚正向但情绪锚已在顶部"。这类股票的上行空间依赖于持续超预期，一旦不超预期就会引发估值杀。不懂四锚的人会在这里追涨，懂四锚的人会退到场外观察。
使用纪律

基于以上示范，给出使用四锚分析的四条纪律。把抽象框架转化为具体个股分析时，始终回到这四条。

  1. 每锚都要看，不要先入为主。很多人只看自己认知最强的那一锚（比如只看基本面或只看资金），这是最容易漏判的。
  2. 四锚打分要多维度。同一个锚可能在一个维度正向、另一个维度负向（比如茅台的盈利锚）。
  3. 关注"锚的切换拐点"。真正的超额收益来自预判锚的切换，而不是跟随已经切换的锚。
  4. 任何分析都有时效性。本页分析的时点是 2026-04-17，市场每天都在变化，一周后很多数据就可能失效。
DISCLAIMER · 免责声明 本页内容纯粹是四锚框架的 应用示范，用来展示如何把抽象框架转化为具体个股的结构化分析。所有具体数据均可能与实际有偏差（基于公开信息整合，非实时交易系统），任何结论都 不应作为投资依据。股市有风险，投资决策需完全依靠独立研究与判断，自负盈亏。
