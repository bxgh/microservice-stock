# 05. 运维部署手册 (Operations Manual)

> **目标**: 提供 Copy-Paste 级别的部署指令，确保环境一致性。

## 1. 端口与网络白名单 (Security Groups)

### 1.1 腾讯云防火墙配置 (Inbound)

| 端口 | 协议 | 来源限制 | 用途 |
|:---|:---|:---|:---|
| **80** | TCP | 0.0.0.0/0 | HTTP (Let's Encrypt 验证) |
| **443** | TCP | 0.0.0.0/0 | HTTPS (Web/API 访问) |
| **22** | TCP | 您的内网IP | SSH 管理 |
| **26300**\ | TCP | 您的内网IP | MySQL 云数据库直连 |
| **6379**\ | TCP | 您的内网IP | Redis (若暴露公网) |

> \*: 如果使用 Docker Network 内部调用，则无需开放 6379 公网访问。但 26300 (MySQL CDB) 必须对内网 IP 开放。

## 2. Docker Compose 编排文件

### 2.1 云端 (`/opt/stock/docker-compose.cloud.yml`)

```yaml
version: '3.8'

services:
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx/conf.d:/etc/nginx/conf.d:ro
      - ./nginx/certs:/etc/nginx/certs:ro
      - ./dist:/usr/share/nginx/html:ro
    depends_on:
      - cloud-api

  cloud-api:
    build: ./cloud-api
    environment:
      - DB_HOST=sh-cdb-h7flpxu4.sql.tencentcdb.com
      - REDIS_HOST=redis
    deploy:
      resources:
        limits:
          memory: 800M

  redis:
    image: redis:7-alpine
    command: redis-server --requirepass ${REDIS_PASSWORD}
    volumes:
      - redis_data:/data
    deploy:
      resources:
        limits:
          memory: 1.5G

  # 数据采集器 (Limit 256M)
  akshare-api:
    build: ./akshare-api
    deploy: { resources: { limits: { memory: 256M }}}
  
  baostock-api:
    build: ./baostock-api
    deploy: { resources: { limits: { memory: 256M }}}

volumes:
  redis_data:
```

### 2.2 内网 (`/home/user/stock/docker-compose.home.yml`)

```yaml
version: '3.8'

services:
  clickhouse:
    image: clickhouse/clickhouse-server:23.8-alpine
    ports:
      - "8123:8123"  # HTTP
      - "9000:9000"  # Native
    volumes:
      - /data/clickhouse:/var/lib/clickhouse  # 挂载大硬盘
      - ./config/clickhouse:/etc/clickhouse-server/config.d
    ulimits:
      nofile:
        soft: 262144
        hard: 262144

  sync-worker:
    build: ./sync-worker
    command: python daily_sync.py
    environment:
      - CLOUD_DB_HOST=124.221.80.250
      - CH_HOST=clickhouse
    volumes:
      - ./logs:/app/logs
    depends_on:
      - clickhouse

  # 策略 Dispatcher (负责启动临时容器)
  strategy-dispatcher:
    build: ./dispatcher
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock  # 允许操作 Docker
```

## 3. 常见问题排查 (Troubleshooting)

### Q1: 内网连不上云端 MySQL (26300)
*   **检查**: `telnet 124.221.80.250 26300`
*   **原因**: 腾讯云 CDB 默认不开启外网访问。
*   **解决**: 登录腾讯云控制台 -> MySQL 实例 -> 开启外网地址 -> 设置白名单包含您的内网公网出口 IP。

### Q2: ClickHouse 启动报错 `Memory limit`
*   **检查**: `docker logs clickhouse`
*   **解决**: 修改 `users.xml` 配置，增加 `<max_memory_usage>10000000000</max_memory_usage>` (10GB)。

### Q3: 回测速度慢
*   **检查**: 是否没走 ClickHouse 而走了 MySQL？
*   **验证**: 查看 Worker 日志，确认 `Loading data from ClickHouse...` 字样。如果走了 MySQL，检查 `scripts/check_connectivity.py` 结果。

## 4. 常用运维别名 (Aliases)

建议添加到 `~/.bashrc`:

```bash
# 云端
alias deploy-cloud="docker-compose -f docker-compose.cloud.yml up -d"
alias logs-cloud="docker-compose -f docker-compose.cloud.yml logs -f --tail=100"

# 内网
alias deploy-home="docker-compose -f docker-compose.home.yml up -d"
alias run-sync="docker exec -it sync-worker python daily_sync.py"
```
