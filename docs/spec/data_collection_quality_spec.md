# A 股数据采集质量与完整性判定规范

**文档 ID**: SPEC-DQ-01  
**状态**: 已锁定 (Locked)  
**适用范围**: 所有行情类（K 线、分钟线、复权因子）采集任务

---

## 1. 核心定义：采集率 (Collection Rate)

为了消除因“停牌”导致的误报，本项目统一采用 **“停牌对冲覆盖率”** 作为判定标准。

### 1.1 基准分母 (Denominator)
- **定义**: 交易日盘前锁定的“理论应采全样本”。
- **计算逻辑**: `SELECT ts_code FROM meta_universe_snapshot WHERE biz_date = T`。
- **样本范围**: 状态为“上市”且上市日期早于当日的 A 股。

### 1.2 采集分子 (Numerator)
- **定义**: 实际成功入库（或通过校验）的代码集合。
- **停牌对冲**: 若某代码在当日 `ods_suspend_d`（停牌表）中，即使采集器未返回数据，**在统计口径上视同采集成功**。

---

## 2. 质量等级与自动化动作 (SLA)

| 等级 | 覆盖率范围 ($R$) | 自动化系统响应 |
| :--- | :--- | :--- |
| **P0 (Perfect)** | $R \ge 99.5\%$ | 正常发布 READY 信号，启动下游 ETL。 |
| **P1 (Normal)** | $98\% \le R < 99.5\%$ | 发布 READY 信号，系统记录缺失列表并在凌晨 02:00 自动重试补录。 |
| **P2 (Degraded)** | $95\% \le R < 98\%$ | 触发“成分股权重检查”：若缺失包含核心宽基成分股，视为失败。 |
| **P3 (Failure)** | $R < 95\%$ | **强制熔断**：主源数据判定为不可信，立即触发全量 Fail-over 至备份源。 |

---

## 3. 存证与血缘 (Lineage)
所有采集任务必须在 `meta_pipeline_run` 中持久化记录当日的 `integrity_report`（JSON 格式），包含具体的 `missing_codes` 和 `failover_reason`。
