# Epic: A 股盘后数据观察体系实施

## 概述
建立从原始数据采集到 9 层派生指标输出的自动化流水线，支撑每日盘后复盘与次日决策。

## 任务分解

### Phase 1: 强化基础监控 (M1 - MVP)
- [ ] **数据源接入**
    - [ ] 实现 `akshare` 涨停池/炸板池采集脚本
    - [ ] 接入 ETF 份额变化数据 (关注国家队信号)
- [ ] **指标计算 (Monitor Service)**
    - [ ] 开发 `SentimentCalculator`: 计算连板高度、封板率、昨日涨停表现
    - [ ] 完善 `raw_market_stats` 回填逻辑
- [ ] **ADS 层建模**
    - [ ] 创建 `ads_sentiment_daily` 表
    - [ ] 创建 `ads_market_overview_daily` 表

### Phase 2: 估值与基本面层 (M2)
- [ ] **历史数据回补**
    - [ ] 编写 10 年指数/行业 PE/PB 历史数据回补脚本
    - [ ] 补齐个股财务摘要 (yjyg, yjkb) 提取逻辑
- [ ] **指标计算**
    - [ ] 开发 `ValuationCalculator`: 实现动态分位数计算 (PE/PB Percentile)
    - [ ] 开发 `FundamentalCalculator`: 实现业绩超预期打分

### Phase 3: 跨市场与全景体系 (M3/M4)
- [ ] **多市场联动**
    - [ ] 接入港股恒生科技、美元汇率、中美利差指标
    - [ ] 实现跨市场相关性监控告警
- [ ] **自动化复盘**
    - [ ] 设计 L9 复盘文案模板
    - [ ] 集成大语言模型 (LLM) 辅助生成每日盘后简报

## 关联微服务
- `akshare-api`: 提供所有原始行情、资金与公告数据。
- `monitor-service`: 核心计算引擎，负责 ADS 层指标生成。
- `stock-manager-api`: 任务调度中心，负责触发采集与计算。

## 验收标准
- [ ] L1-L9 指标每日 20:00 前准时入库。
- [ ] 核心指标（如市场宽度、健康分）缺失率为 0。
- [ ] 能够通过可视化看板或 API 展示 10 年估值分位。
