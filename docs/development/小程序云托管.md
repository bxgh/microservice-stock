后端服务云托管适配改造要求
为确保你的多容器后端能平滑迁移到微信云托管并保持与 VPS 数据的互通，请按照以下清单进行改造。

1. 端口与监听 (Dockerfile & Code)
统一监听端口：确保所有容器在 Dockerfile 或启动命令中监听 80 端口。如果必须使用其他端口，请在部署时在云托管控制台显式指定。
绑定 IP 地址：启动服务时（如使用 uvicorn 或 gunicorn），必须绑定到 0.0.0.0 而非 127.0.0.1。
示例 (FastAPI)：uvicorn main:app --host 0.0.0.0 --port 80
2. 数据库与中间件连接 (VPC 适配)
替换连接地址：将代码中连接 MySQL、Redis、MongoDB 的地址由 localhost 或 127.0.0.1 替换为 VPS 的内网 IP（例如 10.0.x.x）。
使用环境变量：建议不要硬编码内网 IP，而是使用环境变量读取。
示例 (Python)：
python
import os
DB_HOST = os.getenv('DB_HOST', '10.0.0.5') # 默认值为你的 VPS 内网 IP
3. 路由与路径适配
路径前缀对齐：微信云托管网关转发时默认会保留路径前缀（如 /baostock/query）。
确保应用逻辑能处理该路径：
如果你的 FastAPI 路由原本就是 @app.get("/baostock/query")，则无需改动。
如果你原本的应用根路由是 @app.get("/query")，但在云托管配置了路径转发 /baostock/*，则需要在代码中加上 root_path="/baostock"。
4. 腾讯云 VPS 侧配置 (安全组)
网络关联：确保云托管环境与 VPS 处于同一地域，并开启了 VPC 互通。
开放内网访问：在 VPS 的“安全组”设置中，添加入站规则：
协议端口：3306 (MySQL), 6379 (Redis), 以及其他正在使用的内部端口。
来源：填入你的 VPC 网段（通常是 10.0.0.0/16），确保云托管容器能通过内网触达。
5. 打包与日志
依赖清单：确保 requirements.txt 完整，包含生产级服务器组件。
日志输出：确保日志输出到标准输出 (Stdout)，以便在云托管控制台日志流中实时查看。
轻量化：建议使用 python:3.9-slim 等较小的基础镜像，加快上传和启动速度。
