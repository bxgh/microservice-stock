E13-S4 内部数据接口设计手册

Tushare 数据源财务指标及三表持久化写入规范 (Internal API Guide)

1. 资产负债表持久化接口 save_balancesheet

对 A 股资产负债表（合并报表）的季度披露数据进行批量幂等落库，支持上市公司数据更正重写。

@classmethod async def save_balancesheet(cls, data: List[Dict[str, Any]]) -> int:
Tushare 字段 数据库字段 数据类型 说明
ts_code ts_code VARCHAR(12) 股票代码 (唯一键索引分量)
ann_date ann_date DATE 首发公告日期
f_ann_date f_ann_date DATE 实际公告日期
end_date end_date DATE 报告期结束日期 (唯一键索引分量)
report_type report_type VARCHAR(10) 报表类型 (唯一键索引分量)
total_assets total_assets DECIMAL(20,4) 资产总计 (元)
total_liab total_liabilities DECIMAL(20,4) 负债合计 (元)

2. 利润表持久化接口 save_income

对利润表进行批量写入，物理唯一主键保证披露期不发生重复倾泻。

@classmethod async def save_income(cls, data: List[Dict[str, Any]]) -> int:
Tushare 字段 数据库字段 数据类型 说明
ts_code ts_code VARCHAR(12) 股票代码 (唯一键分量)
end_date end_date DATE 报告期结束日期 (唯一键分量)
report_type report_type VARCHAR(10) 报表类型 (唯一键分量)
n_income net_profit DECIMAL(20,4) 净利润 (元)
total_revenue total_revenue DECIMAL(20,4) 营业总收入 (元)

3. 现金流量表持久化接口 save_cashflow

批量写入现金流量表数据，保障自由现金流计算对账的完整性。

@classmethod async def save_cashflow(cls, data: List[Dict[str, Any]]) -> int:
Tushare 字段 数据库字段 数据类型 说明
ts_code ts_code VARCHAR(12) 股票代码
end_date end_date DATE 报告期
n_cashflow_act net_cash_flows_oper_act DECIMAL(20,4) 经营活动产生的现金流量净额
n_cashflow_inv_act net_cash_flows_inv_act DECIMAL(20,4) 投资活动产生的现金流量净额

4. 财务关键指标持久化接口 save_fina_indicator

对收益率、利润率及变动杠杆等关键比率进行计算和保存。百分比字段（如 ROE）会自动除以 100 转换并四舍五入保留 4 位小数。

@classmethod async def save_fina_indicator(cls, data: List[Dict[str, Any]]) -> int:
Tushare 字段 数据库字段 数据类型 清洗规则 说明
ts_code ts_code VARCHAR(12) 直接存储 股票代码 (唯一主键)
end_date end_date DATE 格式化 YYYY-MM-DD 报告期
roe roe DECIMAL(10,4) float(val) / 100.0 净资产收益率 (标准小数)
roe_dt roe_dt DECIMAL(10,4) float(val) / 100.0 扣非净资产收益率 (标准小数)
grossprofit_margin grossprofit_margin DECIMAL(10,4) float(val) / 100.0 销售毛利率 (标准小数)
debt_to_assets debt_to_assets DECIMAL(10,4) float(val) / 100.0 资产负债率 (标准小数)
