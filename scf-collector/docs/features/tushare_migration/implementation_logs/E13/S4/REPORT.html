01 双层幂等排重引擎 (Dual-Layer Deduplication)

为满足用户“防止与MySQL已有重复数据入库”的严格需求，本设计实施了防脏、防冗的双层物理排重引擎：

第一层 (Python 业务更正去重): 针对上市公司“公告更正”引起的多份重名披露期数据，采用 GroupBy 唯一键 (end_date, report_type) 分组，利用公告时序算法仅保留最新版公告，预先过滤垃圾数据。

第二层 (MySQL 物理唯一约束): 利用 uk_code_period_type (ts_code, end_date, report_type) 在行级强制实施防重防漏保护，配合 ON DUPLICATE KEY UPDATE 实现幂等覆盖更新。

02 数据清洗与精度审计 (Auditing & Scrubbing)

本批次数据规范严格执行 A 股专属标准与精度契约：

  • 财务金额标准: 资产、负债、现金流等金额均保持原生态元单位，不加偏置。
  • 百分比标准化存储: Tushare 原生百分比表达的收益率与利润率 (如 ROE 15.5) 在入库前除以 100 统一换算为标准小数 (0.1550)，符合 ADS 层级标准。
  • 防 NaN/Inf 报错机制: 添加 _clean_nan DB 防御处理器，过滤脏值与 pandas 转化带来的非标准浮点 nan 报错，保障物理落库安全性。
