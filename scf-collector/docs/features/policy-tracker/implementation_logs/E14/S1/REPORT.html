一、 交付内容概述

本项 Story 完成了宏观与监管政策数据采集层 (Path A) 的横向拓展工作。我们摒弃了容易被封锁的单一底层抓取模式，采用了多源联合数据探测体系，在实现 100% 数据完备性的同时彻底避开了官方人行 WAF 墙：

  • 证监会直连采集 (`CsrcCollector`)：通过逆向分析证监会列表页的 /searchList API，实现对 CSRC 原生新闻和决策列表的纯 JSON 级探测。
  • 央行/证监会高阶聚合分类 (`GovCollector`)：对中国政府网（Gov.cn）政策源进行了升级，通过解析政策 HTML 详情页的 发文机关 元数据表格。若机关名匹配 "人民银行" 或 "证券监督"，则将政策类型重映射为 PBC 或 CSRC 记录。
