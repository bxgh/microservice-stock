# 央行官网 WAF 屏蔽避坑与国务院政策库动态映射决策

记录在开发 Epic 14 政策跟踪系统时，关于央行及证监会数据源访问受阻的诡异 Bug、探索路径与最终的优选架构决策。

---

## 1. 踩坑记录 (The Pitfall)

在尝试将中国人民银行（`pbc.gov.cn`）以及中国证监会（`csrc.gov.cn`）官网作为直接采集源时，遇到了严峻的安全防御屏蔽：
* **人行官网 403/412 (网宿安防 WAF)**: 直接使用 `httpx` 发起网络请求时，会被网宿安全系统的 Web 应用防火墙（WAF）拦截，返回 403 Forbidden 页面或触发 412 动态 JS 挑战（需要计算动态加密 Cookie）。
* **接口 RSA 签名变动**: 逆向人行搜索接口（`sousuo.www.gov.cn`）需要提取 `athenaAppKey`、`athenaAppName` 以及加载 JSEncrypt RSA 签名头，这类动态加密密钥周期性变动，极易失效造成线上任务大面积报错崩溃。

---

## 2. 方案对比 (Options Explored)

为了跨越人行的安防屏障，我们评估并对比了以下三种技术方案：

| 维度 | 方案 A：云函数嵌入 Headless 浏览器 | 方案 B：逆向 RSA 搜索签名算法 | 方案 C：国务院政策库中转与动态发文映射 |
| :--- | :--- | :--- | :--- |
| **技术实现** | 在 SCF 部署 Playwright 或 Puppeteer，模拟人工点击过 Cookie 挑战。 | 抓包提取前端加密混淆 JS，本地生成 RSA 密文请求头。 | 直接抓取免封锁的中国政府网最新政策 JSON，解析详情 HTML 里的发文机关元数据。 |
| **内存/计算开销** | 极高 (≥512MB 内存)，极易因执行超时（SCF 限制）而被杀进程。 | 极低，纯网络 I/O 交互。 | 极低，纯网络 I/O 交互。 |
| **稳定性风险** | **极高**。云厂商公共出口 IP 极易被网宿安防判定为爬虫并永久封 IP。 | **高**。人行前端盾规则一旦轮转，本地解密算法即刻失效，维护成本巨大。 | **极低 (接近 0)**。中国政府网对爬虫高度友好，且元数据结构数年保持一致。 |
| **开发周期** | 3-5 天 (需要解决 SCF 打包 Linux 浏览器依赖等跨平台问题) | 2-3 天 (需要深入调试 RSA 签名) | **0.5 天** (仅需编写一个简单的 BeautifulSoup 元数据表格解析器) |

---

## 3. 择优决策 (Optimal Choice)

基于金融数据工程的**超高稳定性红线约束**与**SCF轻量化资源要求**，我们果断放弃了强行破解人行官网的方案 A 和 B，选择了**方案 C (国务院政策库中转与动态发文映射)**：

### 核心决策链条
1. **法定同步机制保障完备性**：根据国务院规定，各部委（人行、证监会、财政部等）制定的所有行政规章、规范性文件、宏观政策及通告，**必须且会在第一时间自动同步至中国政府网的政策大数据库**。
2. **免 WAF 零门槛抓取**：中国政府网是面向全网公开的法定公开平台，服务抗负载力极强，对网络请求完全开放，不会产生 WAF 报错或封 IP 问题。
3. **元数据溯源降维打击**：利用中国政府网详情页的标准 `<table>` 政策元数据栏目，通过精确定位解析 `发文机关`。如果出现 `中国人民银行` 则动态将 `ts_code` 映射为 `PBC`；出现 `中国证券监督管理委员会` 则映射为 `CSRC`。

---

## 4. 复用技巧与最佳实践 (Reusable Tips)

在解析发文机关进行分类时，以下解析提取代码属于高度通用的**元数据提取避坑模版**：

```python
# 最佳实践：基于 DOM 相邻节点的高容错发文机关提取
ts_code = "GOV_CN"  # 默认兜底分类
cells = soup.find_all(["td", "th"])
for idx, cell in enumerate(cells):
    text = cell.get_text(strip=True)
    if "发文机关" in text:
        if idx + 1 < len(cells):
            val = cells[idx + 1].get_text(strip=True)
            # 兼容官方全称与缩写
            if "人民银行" in val or "pboc" in val.lower():
                ts_code = "PBC"
            elif "证监会" in val or "证券监督" in val:
                ts_code = "CSRC"
            break
```

> [!TIP]
> **开发警示**：在爬取中国宏观政策和金融监管数据时，**永远不要试图去和人行、外管局等高安防等级站点的 WAF 墙正面硬刚**。优先寻找由国务院、新华社或中国政府网统一聚合、法定的免 WAF 共享接口作为中转，能让您的数据管道稳定性提升数个数量级。
