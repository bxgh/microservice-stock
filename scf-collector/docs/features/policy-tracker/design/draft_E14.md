# Epic 14: AI-Driven Policy Tracking System (MVP)

## 背景
建立一个基于 AI 的政策跟踪系统，解决投资者在处理海量宏观政策信息时的「预警、追踪、对比、映射、日历」五大核心痛点。

## 核心技术栈与部署策略
| 组件 | 技术选型 | 备注 |
|---|---|---|
| 语言 | Python 3.10+ | 兼容 SCF 运行环境 |
| 存储 | Tencent Cloud MySQL | 所有持久化数据存入云数据库 |
| 通知 | WX + Email (SMTP) | 支持双渠道推送 |
| 部署 | Independent SCF | 新建 `scf-policy-monitor` 函数进行独立测试 |

> [!IMPORTANT]
> **开发与部署策略**：
> 1. **独立测试**：为避免影响生产环境的 `scf-collector`，本项目将部署为独立的云函数 `scf-policy-monitor`。
> 2. **分支作业**：所有开发在 `feat/e14-policy-tracker` 分支进行，待 AC 全部通过并灰度运行稳定后再合并主分支。

## E14 AI-Driven Policy Tracking System (MVP)

交付一套基于腾讯云 SCF 的全自动政策监控与分析系统。

### E14-S1 数据采集层建设 (Data Acquisition)
- **任务**: 实现中国政府网、央行、证监会的定时抓取适配器。
- **AC1**: 能够准确解析出「标题、发布时间、正文」等核心字段。

### E14-S2 AI 分析层与措辞对比 (AI Intelligence)
- **任务**: 建立 Prompt 模板库，实现结构化分析输出。
- **AC1**: 对货币政策等敏感领域能识别出强度变化。

### E14-S3 知识库与板块映射 (Mapping & Storage)
- **任务**: 初始化 MySQL 存储，建立行业关键词映射表。
- **AC1**: 政策内容能准确关联至申万一级行业。

### E14-S4 辅助决策与交互 (Reporting)
**角色**: Investment Advisor
**目标**: 自动生成每日简报（微信/邮件）并对持仓影响评分
**价值**: 辅助最终投资决策

#### 任务
- [ ] T1: 开发 HTML 版每日政策简报模板，支持微信推送与邮件发送
- [ ] T2: 集成 SMTP 协议，实现邮件自动投递逻辑

#### 验收标准 (AC)
##### AC1 多渠道简报分发验证
- **Given**: 当日有新政策
- **When**: 触发简报生成任务（对应 L126）
- **Then**: 微信与指定邮箱均能收到排版正确的 HTML 简报

##### AC2 实时告警响应验证
- **Given**: 发现重大政策
- **When**: 采集后 60s 内
- **Then**: 微信预警与邮件紧急通知同时送达（对应 L132）
