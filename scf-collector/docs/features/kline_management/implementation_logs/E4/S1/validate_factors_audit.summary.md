## 2. 踩坑记录与科学归因 (Story Pitfall)

在校验初期，我们遇到了关于 Tushare `pro_bar` 接口复权计算锚点的重大技术细节问题：

### 2.1 踩坑现象 (The Pitfall)
当单独查询单日交易日数据时，例如 `start_date='20260507', end_date='20260507'`，Tushare 的接口在计算 `qfq` 时会将该日 `3.3229` 视为最新因子（因为查询范围仅包含这单日数据），从而忽略了在 `2026-05-15` 发生的最新除权除息（最新累积因子为 `3.3401`），计算出了未完全复权的“漂移价格”，与本地全历史最新因子锚定的计算价格产生了约 0.5% 到 20% 的“假性偏差”，导致假性偏离率飙升至 39.60%。

### 2.2 解决方案与锚点对齐 (Optimal Choice)
1. **全局终点锚定**：我们通过在 `pro_bar` 接口中指定 `end_date='20260518'` 作为计算终点，强制使 Tushare 的计算锚点对齐全市场的最新除权日。
2. **交易精度对齐**：为了消除接口返回的价格字符串因四舍五入到分（2位小数）带来的物理微扰噪声，我们在比对前将本地计算的前复权价与官方价格统一做 `round(P, 2)` 处理。

在应用上述优化策略后，所有 500 个校验点的偏差瞬间收敛到 **绝对 0 偏离**。
